# Getting Started

This wiki describes version 0.15.0.

GrindstoneSkills deepens five of the game's skills (your levels count) and adds four new ones. Perks grow evenly from nothing at level 0 to full at level 100; milestones unlock at a set level. The Skills window becomes a skill book, and skill loss on death is configurable.

| Skill | Kind | Adds |
| --- | --- | --- |
| [Cooking](wiki:Cooking Skill) | game | faster cooking, slower burning, extra food, saved ingredients |
| [Sailing](wiki:Sailing Skill) | new | tougher, faster ships, wider map reveal, Wind Call, Lookout |
| [Woodcutting](wiki:Woodcutting Skill) | game | aimed falls, domino felling, clean splits, old growth, replanting, finds |
| [Pickaxes](wiki:Pickaxes Skill) | game | seams, splash, rich veins, extra ore, Echo, finds |
| [Foraging](wiki:Foraging Skill) | new | wild picks: extra yield, sweep picking |
| [Fishing](wiki:Fishing Skill) | game | a fight on the line, more bites, big and legendary fish, snags, angler's log |
| [Husbandry](wiki:Husbandry Skill) | new | taming, calm creatures, breeding, twins, produce, Animal Feeder |
| [Defense](wiki:Defense Skill) | new | health, damage reduction, regeneration, guard perks, four milestones |
| [Farming](wiki:Farming Skill) | game | faster growth, row planting, auto-replant, giant crops, tending, compost |

## Install

- Install on the server and every client, same version. A server refuses players without it or with another version. Single player needs only your copy.
- r2modman or the Thunderstore app; by hand, `GrindstoneSkills.dll` into `BepInEx/plugins`. Needs BepInExPack for Valheim.
- The server's settings apply to everyone: [Configuration And Compatibility](wiki:Configuration And Compatibility).

## Keys

| Key | Where | What |
| --- | --- | --- |
| K | at the helm, Sailing 25 | Wind Call |
| O | aboard, Sailing 50 | Lookout |
| E | a growing crop someone planted | tend it, once a day |
| E | a tamed animal you cannot command | pet it |
| Shift (held) | placing a seed | plant one, not a row |
| `/fishlog` | chat | your angler's log |
