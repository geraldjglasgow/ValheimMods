# Elite Building Pieces

New building pieces for the hammer, made to sit beside the game's own.

## Features

- **Core wood wall**: core wood logs laid between two posts, the size of a stakewall and snapping like one. 4 core wood.
- **Large core wood wall**: the same wall twice as wide, in one piece. 8 core wood.
- **Core wood door**: a core wood gate the width of a wall, opening away from you like the wood gate. 6 core wood.
- **Core wood double door**: two gates that open together, the width of a large wall. 12 core wood.

All four are in the hammer's Building tab after the wood gate and need a workbench. They use the game's own core wood
look, wear and break like the stakewall and wood gate, and the doors open, lock to wards and sound like the game's.

## Install
Needed on the server and every client. Install with r2modman or the Thunderstore app, or put
`EliteBuildingPieces.dll` in `BepInEx/plugins`.

## Configuration
`BepInEx/config/milkyteam.elitebuildingpieces.cfg`: one switch puts the core wood pieces in the hammer or takes them
out (pieces already built stay). It applies without a restart; the server's values bind every player.
