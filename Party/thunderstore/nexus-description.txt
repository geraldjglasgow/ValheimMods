===== SUMMARY (plain text, one paragraph) =====
Shared parties for Valheim: invites, party chat, a draggable health panel, colored names and always-on map pins, friendly-fire protection, a party-only map ping and an API for other mods. Server synced. Required on the server and every client.

===== DESCRIPTION (BBCode) =====
Shared parties for Valheim: party chat, health bars, map pins and friendly-fire protection for your group.

[size=4][b]Features[/b][/size]
[list]
[*]Parties with one leader and a server-set size cap. Invites are accepted or declined, and parties survive logging out and server restarts.
[*]Commands: [b]/party create[/b], [b]invite[/b], [b]leave[/b], [b]remove[/b], [b]promote[/b], [b]name[/b], [b]p[/b], [b]panel edit[/b] and [b]status[/b] (admin), with short forms [b]/invite[/b], [b]/leave[/b], [b]/remove[/b], [b]/promote[/b] and [b]/p[/b] unless another mod took the word. [url=https://github.com/geraldjglasgow/ValheimMods/blob/main/Party/PLAN.md#commands]All commands[/url].
[*]Party chat: [b]/p <text>[/b] speaks to the party, [b]/p[/b] alone toggles party-chat mode.
[*]Health panel: each member's health, distance and ailments, draggable with [b]/party panel edit[/b]; arrows point to members off screen.
[*]Floating names and map pins in your party color, even with position sharing off.
[*]Death notices: a chat line and a temporary map pin.
[*]Friendly fire: party members cannot hurt each other, even with PvP on.
[*]Party ping: hold Left Alt while pinging the map to ping only your party.
[*][url=https://github.com/geraldjglasgow/ValheimMods/blob/main/Party/PLAN.md#api-for-other-mods]An API for other mods[/url], without a hard dependency.
[/list]

[size=4][b]Install[/b][/size]
Needed on the server and every client. Install BepInExPack for Valheim, then put Party.dll in BepInEx/plugins (or use a mod manager).

[size=4][b]Configuration[/b][/size]
BepInEx/config/com.Party.cfg. Every setting is described in the file and applies without a restart; the server's gameplay values bind every player (Lock Configuration), the display stays your own. The server keeps the parties in BepInEx/config/Party.<world>.parties.yml.
