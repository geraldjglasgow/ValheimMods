===== SUMMARY (plain text, one paragraph) =====
Shared parties for Valheim: invites, party chat, a draggable health panel, colored names and always-on map pins, friendly-fire protection, a party-only map ping and an API for other mods. Server synced. Required on the server and every client.

===== DESCRIPTION (BBCode) =====
Shared parties for Valheim: party chat, health bars, map pins and friendly-fire protection for your group.

[size=4][b]Features[/b][/size]
[list]
[*]Parties: one leader and a size cap set by the server, kept through logging out and server restarts.
[*]Invites: the other player accepts or declines; any member can invite.
[*]Party names: the leader names the party, shown on the health panel.
[*]Party chat: messages only your party sees, or a mode that sends everything you type to the party.
[*]Health panel: each member's health, distance and ailments, draggable; arrows point to members off screen.
[*]Names and map pins in your party colour, even with position sharing off.
[*]Death notices: a chat line and a temporary map pin.
[*]Friendly fire: party members cannot hurt each other, even with PvP on.
[*]Party ping: hold Left Alt while pinging the map and only your party sees it.
[*][url=https://github.com/geraldjglasgow/ValheimMods/blob/main/Party/PLAN.md#api-for-other-mods]An API for other mods[/url], without a hard dependency.
[/list]

[size=4][b]Commands[/b][/size]
The short forms [b]/invite[/b], [b]/leave[/b], [b]/remove[/b], [b]/promote[/b] and [b]/p[/b] work too, unless another mod took the word.
[list]
[*][b]/party create [name][/b]: starts a party with you as leader.
[*][b]/party invite <name>[/b]: invites an online player; starts a party if you have none.
[*][b]/party leave[/b]: leaves your party.
[*][b]/party remove <name>[/b]: the leader removes a member.
[*][b]/party promote <name>[/b]: the leader hands leadership to a member.
[*][b]/party name [text][/b]: the leader names the party.
[*][b]/party p [text][/b]: sends a party message; alone, turns party-chat mode on or off.
[*][b]/party panel edit[/b]: frees the mouse to drag the health panel; [b]done[/b] or Escape ends it.
[*][b]/party status[/b]: lists every party on the server (admins).
[/list]

[size=4][b]Install[/b][/size]
Needed on the server and every client. Install BepInExPack for Valheim, then put Party.dll in BepInEx/plugins (or use a mod manager).

[size=4][b]Configuration[/b][/size]
BepInEx/config/com.Party.cfg. Every setting is described in the file and applies without a restart; the server's gameplay values bind every player (Lock Configuration), the display stays your own. The server keeps the parties in BepInEx/config/Party.<world>.parties.yml.
