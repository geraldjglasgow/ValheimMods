# Changelog

## 0.1.1

- Party pings and death pins on the map are coloured like the party.
- Less work every frame for the health panel, name colours, map pins and arrows.

## 0.1.0

- First release: parties with one leader, a size cap and automatic leader handover, kept through logout and restarts.
- Invites with an accept/decline prompt and a timeout.
- `/party` commands, short forms where free, named parties and admin `/party status`.
- Party chat with a toggle mode.
- A draggable health panel with distance, ailment icons and off-screen arrows.
- Party-colored names and always-on map pins.
- Death notices in chat and on the map.
- Friendly-fire protection and party-only map pings.
- Gameplay settings synced and lockable, display settings personal.
- A public API for other mods.
